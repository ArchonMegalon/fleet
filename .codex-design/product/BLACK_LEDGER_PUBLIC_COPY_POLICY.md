# Black Ledger Public Copy Policy

Allowed public language:
- Debt Heat
- Chemical Complication Flags
- Not the Face
- Lowest Logic Builds
- Chaos Index
- MysAd Density
- Closeout Witnesses
- Package Pressure

Disallowed public language:
- direct player names
- support case identifiers
- provider names
- operator/internal secrets
- sourcebook text
- stigmatizing labels framed as real-person judgement

Public dispatch footer requirement:

`Generated from <receipt> · public-safe seeded preview · no private table data.`

Homepage teaser requirement:
- one latest dispatch card only
- link to `/ledger/dispatches/{dispatchId}`
- include no provider or operator terminology
