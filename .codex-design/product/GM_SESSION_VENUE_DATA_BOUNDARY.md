# GM Session Venue Data Boundary

## Allowed provider payload

- public-safe session title
- scheduled start time
- scheduled end time
- GM display name only if consented
- event description without spoilers
- registration capacity only after verification
- attendee emails only when required and explicitly consented

## Forbidden provider payload

- runner character sheets
- full runner names for private sessions
- character stats
- campaign notes
- GM secrets
- NPC secrets
- hidden maps
- sourcebook or rules text
- combat or initiative state
- Black Ledger hidden state
- support case data
- account secrets

## Safe titles

- Emerald Sprawl - Session 3
- Friday Night One-Shot
- Black Ledger Faction Table

## Forbidden titles

- spoiler reveals
- private player conflict details
- secret NPC or location details

## Core privacy rule

Provider link visibility must not make private campaign state public by accident.
