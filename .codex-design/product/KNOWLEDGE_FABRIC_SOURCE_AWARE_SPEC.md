# Knowledge Fabric Source-Aware Spec

Knowledge Fabric keeps rules explanations trustworthy by requiring:

- visible provenance
- explain receipts
- source-safe summaries
- no copyrighted text leakage

Public route:

- `/rules`
- `/rules/receipts`
- `/rules/receipts/{receiptId}.json`

Boundary:

- shipped MVP with public-safe receipt downloads
- not a total rules oracle
