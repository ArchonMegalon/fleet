# Answerly Support And Humanizer Spec

## Purpose

Bound Answerly Tier 5 to Chummer-owned support and optional safe-answer humanization.

Answerly is one adapter inside `Chummer Instant Help`.
It is not the support product, not a horizon, and not visible as a provider brand in normal UI.

## Allowed

- public support assistant
- install, downloads, and status helper
- feedback and support intake helper
- optional humanizer for `RuleSafeAnswerPacket`
- optional humanizer for Origin Dossier preview text after Chummer has already built the approved source packet

## Forbidden

- authoritative rules backend
- sourcebook-trained rules brain
- sourcebook quote or paraphrase engine
- character legality decision-maker
- private campaign or runner processor
- release truth owner
- calendar booking or live-session routing
- public vendor-branded support surface

## Runtime rules

- `ANSWERLY_ENABLED=false` disables all provider calls
- `ANSWERLY_SUPPORT_ENABLED=false` disables support mode
- `ANSWERLY_HUMANIZER_ENABLED=false` disables humanizer mode
- fallback stays first-party

## Public naming

Public UI label stays `Support assistant`.
Provider naming stays private unless a legal branding requirement forces a revisit.

The product label for the maintenance surface is `Chummer Instant Help`.
Answers should be minimal: next step first, explanation only when it changes the user's action.

## Origin Dossier humanizer loop

Origin Dossier draft text may pass through a Chummer-controlled humanizer loop before the player sees it or before a media packet is created.

The loop may improve:

- tone
- clarity
- pacing
- repeated phrasing
- visible "generated by assistant" tells

The loop may not change:

- approved canon facts
- GM constraints
- character legality
- nuyen, ware, qualities, skills, attributes, or availability
- private/public scope

If the humanized text drifts from the source packet, Chummer discards it and keeps the original draft.
