# Accessibility and Cognitive Load Release Bar

## Purpose

This file makes reduced cognitive load and accessibility part of the flagship release bar instead of a late compliance checklist.

## Product rule

Shadowrun is inherently complex.
Chummer should make the complexity navigable.

That means accessibility is not separate from product quality.
It is part of how the product reduces panic, ambiguity, and fatigue.

## Required release promises

* keyboard-first dense workflows where the product claims expert speed
* high-contrast and readable states for warnings, legality, and modifiers
* reduced-motion-safe critical flows
* screen-reader-safe install, help, explain, and recovery surfaces
* mobile glanceability for recap, readiness, and consequence moments

## Cognitive-load rule

Every major surface should be able to answer:

* what matters right now
* what changed
* what is blocked
* what I should do next

If users must decode decorative noise before they can act, the product is not ready.
