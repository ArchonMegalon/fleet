# Community Event Venue Operating Model

## Rule

Chummer owns the session or event. External venue providers only host the room.

## Venue families

- open community events
- faction salons and public Black Ledger gatherings
- creator and onboarding sessions
- private campaign sessions that still need a live room

## Required boundaries

- provider links are private by default for campaign session venues
- public routes may show venue posture but must not expose private room links
- manual-link mode is the required baseline
- provider create mode is optional and must fail closed when unverified
- attendance sync is optional and requires explicit consent

## Chummer-owned surfaces

- signed-in campaign session venue pages
- public-safe venue posture pages
- closeout receipts and recap continuity
- campaign membership and GM/manage-role authorization

## Provider-owned surfaces

- live room hosting
- optional mirrored registration posture
- optional post-session attendance export after consent

## Forbidden outcomes

- provider becomes campaign truth
- provider receives runner sheets, GM secrets, rules text, or Black Ledger state
- provider-disabled posture still shows a fake create button
- public venue pages leak private session room URLs
