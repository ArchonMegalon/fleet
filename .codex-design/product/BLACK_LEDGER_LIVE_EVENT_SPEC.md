# Black Ledger Live Event Spec

## Scope

Black Ledger may project public event posture and public recap follow-through around live gatherings.

## Boundary

Black Ledger must not become the live-room system of record for private GM session venues.

For BeHuman-backed GM session lanes:

- Black Ledger may consume only Chummer-owned closeout receipts or public-safe recap signals.
- Black Ledger must not ingest private room URLs, GM-only notes, attendance without consent, or provider secrets.
- World-tick truth stays first-party even when a session used an external live room.

## Allowed public posture

- public event announced
- public-safe venue status
- public recap or post-session follow-through

## Forbidden posture

- private campaign room disclosure
- provider-first session ownership
- direct provider ingestion of world-tick state
