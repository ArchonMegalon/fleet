# Public Onboarding Paths for No-Desktop Users

## Purpose

This file defines the minimum public participation path for users who do not yet have the flagship desktop installed.

## Product rule

Desktop remains the expert flagship.
No-desktop users must still be able to discover whether they are welcome, choose a beginner-safe path, and join a run without being blocked before they understand the table.

## Hero path

```text
land on public run
-> understand the table contract and rule environment
-> choose a governed quickstart runner or existing approved runner
-> pass application preflight
-> receive meeting handoff
-> play
-> receive recap and next-step guidance
```

## Required capabilities

* mobile-readable open run listing
* quickstart runner selection
* readable legality and application preflight
* table contract acknowledgement
* schedule and platform readiness check
* accepted-player handoff and recap receipt
* receive the `make me ready` verdict and the one remaining missing item, if any

## Required non-capabilities

No-desktop participation must not:

* pretend the mobile/web lane replaces the flagship desktop
* force full character-building before first participation
* hide blocked conditions behind generic failure copy

## Acceptance rule

Public scale is not ready until a new player can determine in minutes whether they can join a beginner run without first installing a Windows desktop client.
