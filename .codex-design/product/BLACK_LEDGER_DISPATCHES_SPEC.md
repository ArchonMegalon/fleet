# BLACK LEDGER Dispatches Spec

Black Ledger Dispatches are the narrative layer for World Ticks. They are receipt-backed public summaries, not free-floating fiction.

Every public dispatch must derive from a bounded source:

- `WorldTickReceipt`
- `PlayerSafeNewsProjection`
- package-pressure change
- faction-pressure change
- closeout receipt

Required public fields:

- `dispatch_id`
- `world_id`
- `turn`
- `source_receipt_id`
- `title`
- `summary`
- `body`
- involved factions
- involved districts
- package pressure links
- privacy status
- generated by
- human review status
- created at UTC

Public dispatches must not include:

- private campaign data
- support data
- real user names
- email addresses
- sourcebook text
- provider or LTD names
- operator internals
- stigmatizing labels

Public surfaces:

- `/ledger/dispatches`
- `/ledger/dispatches/{dispatchId}`
- homepage latest-dispatch teaser
- optional tick-news email digest link

Verification:

- seeded turn 1 dispatch exists for `emerald-sprawl-prelude`
- archive route returns `200`
- detail route returns `200`
- homepage teaser renders
- dispatch links back to the tick receipt lane
- forbidden-string scan passes
