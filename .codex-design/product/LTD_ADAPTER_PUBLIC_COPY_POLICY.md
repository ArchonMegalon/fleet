# LTD Adapter Public Copy Policy

Public users should see Chummer-owned route names and Chummer-owned promises.

Default posture: no provider brand, LTD label, prompt/generation language, or "AI did this" provenance appears in normal product copy.
Use those terms only in privacy, safety, copyright, legal, or advanced proof contexts where the disclosure changes user trust or consent.

Allowed public phrases:

- public signal board
- vote and follow
- roadmap signal
- closeout receipt
- dispatch draft reviewed
- operator projection unavailable

Forbidden on public pages:

- ProductLift
- Syllabbles
- blipai.app
- Teable
- Emailit
- AppSumo
- LTD
- webhook
- callback secret
- env var names
- provider binding ids
- generated by AI
- prompt
- source packet
- operator receipt
- any provider brand where a Chummer-owned action name is sufficient

Public pages may mention:

- public signal
- roadmap
- changelog
- dispatch
- package request
- account follow-up

Implementation rule:

If a provider-specific term is needed, it belongs in operator docs, not in rendered public surfaces.
