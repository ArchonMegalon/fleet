# Foundry-First VTT Handoff Proof

## Purpose

This file narrows the first VTT/export proof to one excellent target instead of many mediocre targets.

## Product rule

Chummer remains the canonical truth.
The first external play-surface proof should be Foundry-class export quality good enough to stop hand-copying for one real table.

## First proof package

`one runner -> one opposition packet -> one player-safe handout -> one export receipt`

## Why Foundry first

Foundry-class JSON or package export is the best first proof because:

* it matches the source-of-truth and receipt model
* users already ask for structured Chummer-to-VTT handoff
* it is a better proof of export rigor than looser text-only handoff

## Non-goals

* not equal support for every VTT in wave one
* not making Foundry canonical
* not treating export success as proof that the run itself is canonical there
