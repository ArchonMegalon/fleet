# Role Kits and Starter Loadouts

## Purpose

This file defines the first-party answer to gear paralysis and beginner build overload.

## Product rule

Role kits are not flavor bundles.
They are governed starter decisions that reduce cognitive load while staying rule-environment aware and explainable.

## Required kits

The first kit family should cover:

* street samurai
* face
* mage
* decker
* rigger
* general survivor

## What a kit must include

Each kit should specify:

* role intent
* minimum viable gear
* optional upgrades
* legality under the active rule environment
* why each major item is present
* what is still missing for a specific run

## Product use

Role kits should feed:

* ONRAMP
* quickstart runners
* Build Lab
* Ready for Tonight
* open-run application preflight

## Explain rule

Every kit should be able to answer:

* why was this recommended
* what rule environment shaped it
* what would make this illegal
* what can I safely swap
